## Simulating eXtreme Spacetimes collaboration

<img align="right" width="200" src="https://www.black-holes.org/images/lensing/ParaHighRes.png">
Welcome to the github repos of the Simulating eXtreme Spacetimes (SXS) collaboration!
We develop and run supercomputer code for numerically simulating black holes, neutron stars, and beyond.
